# Open Growth websites

Website designs for Open Growth, which builds websites that bring Calgary businesses more calls and bookings.

| Folder | Style |
|---|---|
| `sitesmith/` | Bold and playful |
| `v3-framer/` | Framer-style dark |
| `v2-agent-dark-3d/` | Dark 3D |
| `v1-claude-editorial/` | Editorial |

Open any folder's `index.html` in a browser. Shared images are in `assets/generated/`.
